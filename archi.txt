KEY DESIGN DECISIONS
────────────────────
core/models.py       Pure Python dataclasses. No SQLAlchemy, no Pydantic.
infrastructure/db/orm_models.py  SQLAlchemy ORM classes only. Mapped to DB tables.
schemas/             Pydantic models only. Used at the API boundary (in/out).

Routers never import repositories directly.
Services never import FastAPI or Pydantic.
Core never imports SQLAlchemy or FastAPI.

ID format:  PREFIX-YYMMDD-NNNNN  (e.g. REC-250122-00001)
Prefix is determined by DocType for files/transactions, table name otherwise.
Generated in Python (not SQL) for SQLite compatibility.
